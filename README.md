# Skm@555 ♾️

Art portfolio and shop website by **Shubham Maurya**, hand-drawn sketches and a daily pocket journal.

**Live site:** https://skmaurya05550.github.io/Skmart/

## What is on the site

- **Live studio time** in IST, with a session line that changes through the day
- **Sketch session timer** that tracks how many minutes you sketched today
- **Showcase** of sketches as glowing prints, with price stickers and Buy this buttons
- **Order form** with name, phone, delivery address and PIN code. It prepares a message to copy and send on Instagram
- **Supplies** section for art products with affiliate links
- **Contact** cards for Instagram and YouTube, plus a Delhivery parcel tracking box
- Neon, futuristic dark theme with a drifting grid, glowing borders and redrawing line art

## Files

- `index.html` : the whole site (HTML, CSS and JavaScript in one file)
- `README.md` : this file

## Run it

Open `index.html` in any browser. No build step and no install. Fonts load from Google Fonts, so an internet connection is needed for the intended look.

## Publish on GitHub Pages

1. Open the repository Settings, then Pages.
2. Set Source to Deploy from a branch, branch `main`, folder `/ (root)`.
3. Save. The site goes live at https://skmaurya05550.github.io/Skmart/ within a couple of minutes.

## Edit the basics

All settings are near the top of the script at the bottom of `index.html`:

- Prices and items: the `SHOP` list
- Sample sketches: the `SAMPLES` list
- Time zone: the `tz` value, currently `Asia/Kolkata`
- Colours and fonts: the `:root` variables at the top of the style block
- Instagram and YouTube handles: the Contact section in the HTML

## Notes

- Photo uploads and supply products with affiliate links need Claude's built-in storage, so they work on the claude.ai version of the page. On GitHub Pages the showcase shows the sample sketches and Supplies stays empty.
- Orders are not stored or sent automatically. The visitor copies the prepared message and sends it by Instagram direct message.
- Prices in the file are starting values. Change them to your real prices.
